# 扩点树与现金流

根period=0，子period=父period+1，每非根节点恰一父，无合流、孤立节点或循环。actions为可选新增整数，选完装机数不超过capacity_limit，新增×purchase_cost不超过本节点budget；初始installed固定。未到达的零概率节点仍要求政策给出合法动作，概率只影响期望和CVaR。收入表operating_cash索引为动作后装机数，已经扣除本期运营费用，不再额外乘需求或概率。叶节点在同一期加salvage_per_unit×装机数，所有金额均分数串，rate>-1，0<alpha<1。没有资金滚存约束，budget是每期独立授信而非上一节点现金余额。

稳定决胜顺序为node id字典序，政策向量包含全树节点（即使当前概率为零）。有理数精确比较可避免风险界附近误判。预知未来上界对每条叶路径单独最大化NPV后按概率求期望，不受全局风险上限，因而是所有可实施风险可行政策期望的乐观上界。normal最多每节点三种动作，全树合法策略空间很小；max_policies为硬资源限额而不是不可行条件。

domain只验证子节点概率并对illustrative_cash做折现，不搜索政策或评价整棵树。
