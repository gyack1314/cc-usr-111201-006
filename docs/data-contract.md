# 扩点树与现金流

根period=0，子period=父period+1，每非根节点恰一父，无合流、孤立节点或循环。actions为可选新增整数，选完装机数不超过capacity_limit，新增×purchase_cost不超过本节点budget；初始installed固定。未到达的零概率节点仍要求政策给出合法动作，概率只影响期望和CVaR。收入表operating_cash索引为动作后装机数，已经扣除本期运营费用，不再额外乘需求或概率。叶节点在同一期加salvage_per_unit×装机数，所有金额均分数串，rate>-1，0<alpha<1。没有资金滚存约束，budget是每期独立授信而非上一节点现金余额。

稳定决胜顺序为node id字典序，政策向量包含全树节点（即使当前概率为零）。有理数精确比较可避免风险界附近误判。预知未来上界对每条叶路径单独最大化NPV后按概率求期望，不受全局风险上限，因而是所有可实施风险可行政策期望的乐观上界。normal最多每节点三种动作，全树合法策略空间很小；max_policies为硬资源限额而不是不可行条件。

domain只验证子节点概率并对illustrative_cash做折现，不搜索政策或评价整棵树。

## 决策模块口径

`analysis_data.model`把资料构造成分数精确的有限根树（`Fraction`全程运算，拒绝布尔与浮点），`analysis_data.solver`在树上枚举确定性、非随机化政策。政策是节点id到动作的全函数：包括零概率节点在内的每个节点都必须给出合法动作，枚举从不删枝，因此零概率分支不会改变决胜向量。政策空间大小由`count_legal_policies`独立给出，`max_policies`是硬资源限额：枚举达到限额即返回`not_completed`，不返回政策、不声称不可行或最优；只有完整枚举后仍无风险可行政策才返回`infeasible`。

叶损失是该叶总折现NPV的相反数（允许为负）。风险量按定义精确计算：对离散分布，凸函数`eta+E(max(loss-eta,0))/(1-alpha)`在损失样本点取到最小值，求解器在去重后的损失点上枚举eta取最小，零概率叶不进入期望与CVaR。选优层级为：CVaR不超过损失上限的政策中期望NPV最大；期望相同按node id字典序的动作向量字典序决胜（取较大向量，结果确定性可复现）。模块不做任何局部风险剪枝，也不把各节点局部最优拼成全局政策。

`analysis_data.checker`是独立检查器：只复用model的结构解析，现金流遍历、政策枚举、期望、CVaR、预知上界全部用与solver不同的代码重新实现。它拿报告中的政策从根重新遍历树（不信任求解器缓存的NPV），完整重新枚举并核对最优性、风险、叶路径逐笔金额、预算合规与上界，任何不一致抛`CheckError`。

预知未来上界（`hindsight_foresight_upper_bound`）对每条根-叶路径单独最大化NPV，等价于今天就知道终点，同一节点可在不同叶路径下选不同动作，报告用`node_action_conflicts`显式列出这些冲突，并固定标记`implementable=false`。它不受风险上限约束，只是可实施政策期望的乐观上界，差距`foresight_gap`即事后挑选带来的虚高。
